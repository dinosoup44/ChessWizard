Record observations, not expectations. Never disable Windows security. A Defender
alert or execution block must be investigated, not treated as a successful test.
If execution is blocked before the guide opens, retain the warning and fill this
form; there is no need to bypass security just to create a PASS receipt.

USB copy may not reproduce browser/Internet-zone behavior. A USB run can prove
functional checks but leaves downloaded-file behavior OPEN. A separate browser
observation must use the exact candidate hash, without removing Internet-zone
metadata, and be returned as supplemental evidence. The owner may arrange a
private transfer; this task does not authorize a public installer upload.

No warning seen on a USB copy does not mean no warning on a browser download.
Attach this form and any named screenshot to the original receipts; do not edit
original JSON. Do not record unrelated personal or machine identifiers.
