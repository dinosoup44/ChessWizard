CHESSWIZARD 1.0.0-beta - WINDOWS TESTER QUICK START

1. Extract ChessWizard_CURRENT_INSTALL.zip (or the versioned Windows ZIP) completely.
2. Run ChessWizard-1.0.0-beta-Windows-x64-Setup.exe.
3. Leave "Create a desktop shortcut" checked (it is on by default).
4. Open ChessWizard from the Desktop or Start Menu.
5. Choose File > Import Games, choose Chess.com or Lichess, and enter your username.
   Use Tools > Analyze Games after importing. Internet is needed for username imports.

Requires Windows 10/11 x64 and an AVX2-capable processor. Python, Git and a
separate Stockfish installation are not needed. Analysis runs locally.

Your games, settings, themes and managed opening libraries live in:
%LOCALAPPDATA%\ChessWizard
The program installs separately in %LOCALAPPDATA%\Programs\ChessWizard.
Uninstall keeps your data. Exported .cwbook files remain where you saved them.

This is an unsigned beta. Windows may display an unknown-publisher notice.
Keep your own backups. Report problems to the person who supplied this beta:
include the version, what you clicked, expected/actual behavior and a screenshot.
Share personal game/data files only if you choose to.

SOURCE-NOTICE.txt explains the accompanying source archive. It is not required
for installation, but must accompany this beta when you pass it to someone else.
