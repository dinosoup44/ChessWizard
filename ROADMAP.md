# Roadmap

The application label remains **1.0.0-beta**. V1.5 is the installer/plugin foundation
checkpoint. The directions below are not release dates or completed releases.

## V1.5 release validation (feature freeze)

Per-user installation, repair/upgrade, safe uninstall and API V1 plugin lifecycle
are implemented on review branches. Remaining acceptance includes a genuinely clean
Windows machine, human installer/Plugin Manager review at three DPI settings, and
an explicit signing/distribution decision. See the [release checklist](docs/FIRST_PUBLIC_RELEASE_CHECKLIST.md).
Public version bump, merge, tag and upload require separate owner approval.

## Existing study functionality (frozen during V1.5)

- Game Review, stored evaluations and move-quality feedback.
- Evidence-based tactical specialists and reusable proof/cache infrastructure.
- Editable Opening Studio, Opening Review and a reproducible default opening library.
- Training from saved tactical candidates.
- Performance, analysis completeness, navigation and data-safety hardening.
- Public-source privacy, contributor documentation and reproducible validation.

## Future V2 candidates (not part of V1.5)

- Critical Moment Engine, building on existing factual context helpers.
- Additional tactic specialists and clearer mate-pattern labels.
- Endgame truth and possible Syzygy integration after the evidence contract is defined.

## Future exploration

- The Professor: modular lessons using shared services.
- Richer statistics over user-owned history.
- ARM and resource-constrained environments.
- Experimental player-style bots.
- Alternative/mobile frontends reusing the core; no mobile implementation is promised.

Analyzer truth and safe incremental changes take priority over the number of features.
