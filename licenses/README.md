identified official license URLs. `provenance.json` records original locations,
SHA256, byte counts and check date. Root LICENSE is the complete GNU GPL v3 text;
COPYING.md applies the version-3-or-later grant to ChessWizard.

Retain the **entire** Pillow license file: it contains licenses for native codec,
font and compression components as well as Pillow. Retain both Python documents,
its Windows additional conditions, Tcl/Tk embedded notices, Tk image permission,
LibTomMath/zlib-ng notices and the Mozilla Public License for embedded PSL data.
Do not treat the first PSF or MIT paragraph as the entire runtime license set.

Stockfish AUTHORS, Copying.txt and upstream README remain unchanged. The README
also preserves upstream training-data acknowledgements; CC0 applies to the
identified network files per the official networks repository. No training
corpus, private theme or external artwork is included by this notice directory.

`release_files.json` is an explicit license/document include list, not a packager
spec and not a recursive project-copy instruction. No reports, user paths, DBs,
review data or settings belong in it. `source_info/runtime_inputs.json` records
candidate inputs. The actual frozen manifest and final license check are recorded
in the local packaging reports; internal audit manifests are not runtime assets.
PyInstaller COPYING.txt is copied from its exact 6.22.3 installed distribution
and includes the bootloader exception and complete Apache runtime-hook terms.
