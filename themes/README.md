# ChessWizard artist themes

Launch `C:\Projects\ChessWizard\.venv\Scripts\python.exe C:\Projects\ChessWizard\run_art_tester.py`.
Export static transparent PNGs from your preferred art program, choose one per piece,
set board colors, preview, and Save Theme. All 12 roles are required for complete
status; partial sets remain drafts. Every save creates a separate managed snapshot.

Do not place executable files, archives, scripts or plugins in a theme. No code is
loaded from themes. See `../docs/THEMES_AND_ART.md` for limits and decoration slots.
The README is root documentation, not a file inside an installed theme package.
